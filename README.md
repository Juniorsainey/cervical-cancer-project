

Course Title: Data Engineering
Assignment: Data Analysis, Modeling, and Presentation Project
Assignment Overview
This assignment is designed to develop students’ practical skills in data engineering, statistical
analysis, and predictive modeling using real-world datasets. Students will work in groups to
explore domain-specific datasets, apply statistical techniques, build analytical models, and
communicate insights effectively.

Group Allocation and Topics
Students are required to work in six (6) groups, each focusing on a specific domain:
 Group 1: Rainfall Analysis
 Group 2: Cancer Data Analysis
 Group 3: Diabetes Analysis
 Group 4: Heart Disease Analysis
 Group 5: Asthma Analysis
 Group 6: Denial of Service (DoS/DDoS) Cybersecurity Analysis

Assignment Tasks
1. Dataset Acquisition
Each group must:
 Identify and download a relevant dataset from reliable sources such as:
o Kaggle
o UCI Machine Learning Repository
o WHO, World Bank, or Government databases
 Provide a description of the dataset, including:
o Source
o Number of variables and observations
o Data types (numerical, categorical, time-series, etc.)

2. Data Preprocessing and Exploration
Students should:
 Clean the dataset (handle missing values, duplicates, outliers)
 Perform exploratory data analysis (EDA):
o Summary statistics (mean, median, variance, standard deviation)
o Visualizations (histograms, boxplots, scatter plots, correlation heatmaps)

3. Statistical Analysis
Apply appropriate statistical formulas and methods, such as:
 Measures of central tendency and dispersion
 Correlation and covariance
 Hypothesis testing (if applicable)
 Probability distributions (where relevant)

4. Model Development
Using R or Python, students must:
 Build at least one statistical or machine learning model, such as:
o Linear Regression (e.g., rainfall prediction)
o Logistic Regression (e.g., disease classification)
o Decision Trees / Random Forest
o Time Series Models (for rainfall)
o Classification models (for DoS/DDoS detection)
 Justify the choice of model
 Train and test the model
 Evaluate performance using appropriate metrics:
o Accuracy, Precision, Recall, F1-score (classification)
o RMSE, MAE (regression)

5. Interpretation of Results
Students should:

 Interpret findings clearly
 Explain trends, patterns, and anomalies
 Relate results to real-world implications (e.g., public health, climate, cybersecurity)

6. Report Writing
Each group must submit a comprehensive report structured as follows:
Report Structure
1. Introduction
2. Background of the Study
3. Problem Statement
4. Objectives of the Study
5. Dataset Description
6. Methodology
7. Data Analysis and Results
8. Model Development and Evaluation
9. Discussion of Findings
10. Conclusion and Recommendations
11. References

7. PowerPoint Presentation
Each group must prepare a PowerPoint presentation (10–15 slides) including:
 Topic overview
 Dataset description
 Key visualizations
 Model explanation
 Results and insights
 Conclusion
Presentation Duration: 10–15 minutes per group

Tools and Technologies
Students may use:
 Python (Pandas, NumPy, Matplotlib, Scikit-learn, Seaborn)

 R (tidyverse, ggplot2, caret)
 Jupyter Notebook / RStudio

Assessment Criteria (20 Marks)
Component Marks
Dataset Selection &amp; Understanding 2
Data Cleaning &amp; EDA 2
Statistical Analysis 2
Model Development 5
Interpretation &amp; Insights 2
Report Quality 6
Presentation 6
Total 30

Submission Requirements
 Report (Word)
 Source Code (R/Python scripts or notebooks)
 Dataset (or link to dataset)
 PowerPoint Slides
